compositing or replacement artwork.

Original client files and generated assets used to render these views are not
part of the public source or Elbera Tools Core archive. The screenshots are
selected illustrations of development output, not redistributable asset packs.

Other images in this directory are historical captures. They are not a current
release certification; the [coverage inventory](../PORT-COVERAGE.md) takes
precedence over older captions or inferred completeness.
